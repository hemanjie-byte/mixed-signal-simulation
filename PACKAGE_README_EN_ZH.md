# V3.3 package

# V3.3交付包

Extract all files together and open index.html. Keep the v33/education assets beside the viewer. Every model has an English GIF and a static poster; Excel links to the published GIFs and displays posters, native charts and formula-based error reduction. Numerical values remain authored examples, not measured or PDK-calibrated devices.

将全部文件一起解压后打开index.html，保留v33/education资源。每项模型有英文GIF与静态海报；Excel链接已发布GIF，并展示海报、原生图表及误差下降公式。数值仍为人为示例，不是实测或PDK校准器件。

The package includes current V3.3 data/code and preserved V3/V3.2 source/JSON needed to reproduce the comparisons. It omits historical CSV duplicates, older workbooks/ZIPs and V1/V2 trees. Old historical relative links may require the full repository. No paper PDFs or private research caches are included. Check v33/validation/release_manifest.json for SHA-256 hashes.

包内含当前V3.3数据/源码及复现对比所需的V3/V3.2源码与JSON；省略历史CSV副本、旧工作簿/ZIP和V1/V2目录。历史相对链接可能需要完整仓库。不含论文PDF或私有研究缓存。SHA-256见v33/validation/release_manifest.json。
