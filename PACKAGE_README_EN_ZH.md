# V3.2 delivery package

# V3.2交付包

Extract all files together, then open index.html locally. The Excel workbook is a static simulation snapshot with editable voltage screening, terminal-power and loss-ledger arithmetic. The Classroom sheet has a still poster; play v32/education/buck_energy_flow.gif for animation. Numerical source code, CSV/JSON, tests, evidence links and model limits are included. No third-party paper PDFs or private research caches are distributed.

将全部文件一起解压，再本地打开index.html。Excel为静态仿真快照，支持电压筛选、端口功率及损耗台账算式编辑重算。Classroom表为静态海报，动态演示见v32/education/buck_energy_flow.gif。包含数值源码、CSV/JSON、测试、证据链接与模型限制；不分发第三方论文PDF或私有研究缓存。

The package includes preserved V3.1 source/data and the new V3.2 work, but excludes the older V1/V2 trees and prior workbook/ZIP files. Historical relative links may need the full GitHub repository. A manifest records SHA-256 for every included file except itself and the ZIP. Regeneration can change elapsed-time fields and image font pixels without changing numerical intent.

包内包含保留的V3.1源码/数据与本轮V3.2内容，排除更早V1/V2目录及旧工作簿/ZIP；历史相对链接可能需要完整GitHub仓库。清单记录除自身与ZIP外每个文件的SHA-256。重新运行可能改变耗时字段及字体像素，不等于数值含义改变。
