1. What switches?什么在开关？
The transistors alternately connect the switch node to the input and the return path. The inductor keeps current continuous.晶体管交替将开关节点连接到输入和续流回路。电感使电流保持连续。
2. What sets the output?什么决定输出？
In ideal continuous conduction, D ≈ Vout/Vin. For 12 V from 40/100/150 V, D ≈ 30/12/8%. Higher input means a shorter on-time.理想连续导通时，D≈Vout/Vin。40/100/150V降到12V，占空比约30/12/8%；输入越高，导通时间越短。
3. Why add analog models?为什么还要模拟模型？
Gate charge, diode recovery, dead time, bootstrap droop and sensing delay create losses and timing constraints that the ideal duty equation omits.栅电荷、二极管恢复、死区、自举压降和检测延迟引入理想占空比公式未包含的损耗与时序约束。
4. What is a model boundary?什么是模型边界？
An averaged controller explains startup over many cycles. A switching bench explains one commutation. Neither substitutes for an authorized foundry model or measured hardware.平均控制模型解释多个周期内的启动过程；开关测试台解释一次换流。二者都有明确适用范围，工艺签核仍需要授权模型及实测。
