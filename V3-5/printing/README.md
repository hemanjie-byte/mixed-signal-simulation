# Printable teaching structures

# 可打印教学结构

Use the [gallery](index.html) to choose any of the 75 entries and switch between beginner, undergraduate and graduate explanations. Each entry links directly to its STL and preview; the [print index](print_index.csv) provides a compact list.

通过[图库](index.html)选择 75 项条目中的任一项，并切换入门、本科、研究生讲解。每项直接链接 STL 和预览，[打印索引](print_index.csv)提供精简列表。

Import STL in **millimetres**. Footprints are **60 × 42 mm**; heights vary by entry. These are enlarged microstructure/circuit teaching concepts. Colors represent relief height, not materials or electrical fields. A printable structure does not certify an electrical model. Mesh checks pass; physical printing and printer-specific slicing have not been tested. See the [printing guide](PRINT_GUIDE_EN_ZH.md).

STL 导入单位选**毫米**，底面 **60 × 42 mm**，各条目高度不同。它们是微观结构或电路的放大教学概念。颜色代表浮雕高度，不代表材料或电场。可打印结构不等于电学模型认证。网格检查通过，尚未经实物打印及特定打印机切片验证。详见[打印指南](PRINT_GUIDE_EN_ZH.md)。

The small `sources/V1-0` and `sources/V2-0` folders retain only descriptive geometry/catalogue inputs required to trace older teaching entries. Full former releases remain in Git history.

精简后的 `sources/V1-0` 和 `sources/V2-0` 仅保留追溯旧教学条目所需的几何及目录输入；完整旧版保留在 Git 历史中。
